# Tetris

C로 작성한 터미널 테트리스입니다. 순위 저장·조회와 블록 배치 추천, 추천에 따른 자동 플레이 기능을 구현했습니다.

## 기능

- 방향키를 이용한 블록 이동·회전, 자동 낙하와 점수 표시
- 이름과 점수의 로컬 저장, 순위 조회·삭제 메뉴
- 추천 위치 표시와 자동 플레이

## 빌드와 실행

C 컴파일러와 ncurses 헤더·라이브러리가 필요합니다. macOS에서는 Xcode Command Line Tools가 설치된 환경을 사용합니다.

```sh
./build.sh
./run.sh
```

터미널 크기는 40열 × 26행 이상을 권장합니다. 


## 조작

| 입력 | 동작 |
| --- | --- |
| 메뉴 `1` / `2` / `3` / `4` | 직접 플레이 / 순위 / 추천 플레이 / 종료 |
| `←` / `→` | 좌우 이동 |
| `↑` / `↓` | 회전 / 한 칸 내리기 |
| 게임 중 `q`, 이어서 아무 키 | 메뉴로 돌아가기 |
